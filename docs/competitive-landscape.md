# 类似产品调研

调研日期：2026-11-11。依据下列官方网页和文档，未注册或实测产品；描述是官方宣称的能力，不代表独立性能验证。未核实价格、地区可用性或完整功能覆盖。

## 产品比较

| 产品 | 官方描述的侧重点 | 与 WakenX 的重合 | 对 WakenX 的启发（判断） |
| --- | --- | --- | --- |
| [Lindy](https://www.lindy.ai/docs) | 邮件、日程、会议准备、跟进及主动例行任务 | 个人与工作事务代理，重合度高 | 日常简报和跟进已是竞争点，需要验证更具体的人群与效果 |
| [Poke](https://poke.com/docs) | 在 Apple Messages、Telegram、WhatsApp、RCS 中处理邮件、日历、提醒和搜索 | 低门槛的个人助理入口，重合度高 | 尽量融入用户已有沟通习惯，减少管理 Agent 本身的成本 |
| [Ohai](https://www.ohai.ai/features/) | 家庭日程、提醒、任务，以及学校日程信息提取 | 家庭场景重合度高 | 家庭协作需要明确成员、责任和共享边界，不能只增加共享待办 |
| [Motion](https://www.usemotion.com/help) | 根据任务、优先级、截止日期和可用时间持续安排工作日程 | 优先级与注意力分配相邻 | 待办应结合现实时间容量，避免不断提醒却无法完成 |
| [Manus](https://help.manus.im/en/articles/17768086-what-are-the-differences-between-chat-mode-and-agent-mode) | Agent 模式自主规划和完成复杂任务，输出网站、幻灯片等成果 | 通用任务执行相邻 | 需要清晰的完成标准与成果交付，持续事务管理可作为待验证侧重点 |
| [OpenClaw](https://openclaw.ai/) | 自行运行的开源个人助理，通过聊天入口连接邮件、日历等工具 | 个人 Agent 方向重合度高，也可作为技术参考 | 可评估复用现有执行能力，把产品投入集中在体验与任务可靠性；尚未做代码或许可评估 |

Lindy 的具体产品能力另见[官方功能页](https://www.lindy.ai/product)，家庭协作另见 [Ohai 官方介绍](https://www.ohai.ai/features/ai-household-collaboration-tools/)。

## 初步结论与定位建议

类似产品已经存在，个人、家庭和工作三个场景都能找到对标。“覆盖三个场景”本身不足以证明差异化；本次调研也不能证明市场存在无人覆盖的空白。

建议将 WakenX 的待验证主张收窄为：替用户持续跟进重要事务，合并常规进展，只在需要判断或存在风险时请求注意力。

建议从个人待办的持续跟进入手，以节省的追踪时间、无用提醒比例、按期完成率和纠错成本衡量价值。首个验证场景可以是：用户提交一项带截止日期的承诺，由 Agent 协助明确下一步、定期跟进，并在约定时间汇总结果。家庭与工作场景作为后续扩展，不同时铺开。

这是一项产品假设，不是已确认的竞争优势。下一步应对 Lindy、Poke 和 Ohai 做相同任务的实际试用，并访谈目标用户，再确定实现路线。
