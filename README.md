# WakenX

Agents for personal life, family, and work—helping people focus on what matters most.

WakenX 是面向个人、家庭和工作场景的 Agent 产品，承接日常事务、持续跟进任务，让人的注意力聚焦于更关键的事项。

## 当前状态

项目处于产品定义阶段。本仓库包含定位、首版计划、类似产品调研和独立的前端交互原型。原型使用全虚拟数据，不代表已上线产品或已实现的真实 Agent 能力。

## 交互原型

- [偏好不等于授权 Demo](wakenx-demo/README.md)：直接用浏览器打开 `wakenx-demo/index.html`；包含截图、故事板、20 秒演示脚本和验收记录。

## 产品方向

- 个人：待办收集、目标跟进和每日简报。
- 家庭：共享日程、事项分工和协作提醒。
- 工作：行动项整理、进度跟进和会议准备。

先验证个人场景中的待办跟进闭环，再逐步扩展家庭和工作协作。
